[discrete]
=== Session Continuity — Cumulative Structure

The core design principle of this workshop is _accumulation_.

* The _TeamOrder case_ begins with one sentence in Session 1 and runs identically through Session 8
* _Worksheet B_ deepens participants' real-work cases across all 8 sessions
* Each session's assignment feeds into the next session's opening connection
* _Sessions are not independent._ If a session is missed, the following session becomes difficult

'''

[discrete]
=== Core Message — The Entire Workshop

The one thing participants should take from this workshop:

[quote]
____
_"Spending more time on the problem is how you build the solution faster."_
____

When the Problem Space is explored more thoroughly:
* What must essentially be achieved becomes clear
* What can wait becomes visible
* What does not need to be built is identified
* → Build less and more precisely, and deliver earlier
