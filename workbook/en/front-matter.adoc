=== How This Workbook Is Organized

This workbook is the _participant_ material for the workshop.
It is a space to write, fill in, and record during each session.

----
Worksheet A  Fixed case exercise forms provided for each session
             The TeamOrder case is explored session by session using different tools

Worksheet B  A form for carrying a single real-work case across all 8 sessions
             Each session applies the new tool to your own real-work problem
             At the end of Session 8, you will have one completed analysis

Assignment   A short practical task to complete at work after each session
Card
----
